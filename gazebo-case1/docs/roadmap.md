# 优化与后续验证

## 1. 先处理绕行时的邻机间距

四场单箱对照中，A、B 的障碍净距仍约为 0.375 m，相邻航线的最小机间距从约 1.98 m 降至 1.046 m。先给相邻航线加入局部让行，把“绕箱路线”和“邻机通过时刻”放在一起检查。优先评估只调整一架的进场时机或速度，加完一项就重跑 A、B 和双箱定稿的同一组初始状态。

验收以机体包络和项目选定的机间安全裕量为基础，比较最小间距、最小障碍净距、回位时间和是否保持七机落地。原有仿真数值与新结果同表记录。

## 2. 检查 S6 重组期间的求解和瞬态

四轮冻结复跑的最近机对均为 UAV-4/UAV-6，采样最小间距约 1.436–1.471 m。求解回退主要发生在 UAV-4/UAV-5 的前段重组。把角色事件、各机求解状态、速度指令和局部机对距离放到同一时间线上，先确定反复出现的时段，再分别对比热启动和重组速度限制。比较时保留原事件顺序和最终槽位作为验收项。

## 3. 扩展静态障碍的复杂度

目前双箱按先复队、后绕第二箱的顺序运行。下一轮可逐步缩短两箱距离，记录两段相互接近时的最小机间距与可行轨迹。已有串联隔离区的控制器会检查规划窗口是否重叠。要支持重叠，需要能协调同一时间内多组飞机的绕行、让行和重入航线。

## 4. 引入感知和更真实的模型

先让模拟相机或激光雷达提供静态障碍位置，再对感知误差、延迟和短时缺测逐项做可重复验证。静态地图与传感输入应使用相同的普通场景和验收指标。若以后接 PX4 SITL，可先验证单机起降和位置接口，再扩展机数。当前版本的视觉机身是 Mavic 风格，飞行动力学使用 Open Robotics X3。
