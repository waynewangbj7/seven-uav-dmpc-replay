## 怎么跑（在本机 WSL 里）

环境要求正是本机现状：WSL 2 + Ubuntu 24.04 + ROS 2 Jazzy。

```bash
mkdir -p ~/seven-uav && cd ~/seven-uav
unzip /mnt/c/Users/王志勇/Desktop/文献/文献复现/文献1/seven-uav-ros2-rviz-2026-11-21.zip
cd seven-uav-ros2-rviz-2026-11-21

source /opt/ros/jazzy/setup.bash
python3 replay/replay_case1.py --archive "$PWD/case-data" --rviz
```

- rviz2 弹出后左侧应有 `City` 和 `Seven UAVs`
- 终端会打印面板地址（默认 `http://localhost:8765/`），用 Windows 浏览器打开
- 点 **6.6 s · S6** 再点「上一帧」，可对照编队合并前后

常用参数：

| 参数 | 作用 |
|---|---|
| `--seed 8` | 切换种子（7–11） |
| `--speed 0.5` | 慢放 |
| `--panel-port 8766` | 换面板端口 |
| `--mesh replay/fixed_wing.obj` | 换固定翼机模 |
| `--check-data` | 只校验数据，不起 ROS |

> 注意：桌面上已解压的 `文献复现\文献1\seven-uav-ros2\` **缺 `case-data/`**，直接用 zip 解压更可靠。
