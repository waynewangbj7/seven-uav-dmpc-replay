## 复算方法

数据源：`case-data/work/engineering_case1/seed_7/states.csv`

### 输入格式

```
time,agent_id,role,coordinator,slot,x,y,speed,yaw,accel,yaw_rate,controller,valid_neighbors_used
0.0,UAV-1,leader,UAV-3,1,0.0,0.0,75.0,...
0.0,UAV-2,follower,UAV-3,6,-105.0,-185.0,89.0,...
```

每行是一架飞机在某一时刻的状态，`x`、`y` 是平面坐标（米）。

### 算法

1. 按 `time` 分组，每组应有 7 行
2. 组内计算全部两两距离：C(7,2) = **21 对**
3. 对每一对求 `sqrt(dx² + dy²)`
4. 取全程最小值，记录它出现的时刻与机对

### 复算脚本（PowerShell）

```powershell
$lines = ($text -split "`r?`n") | Where-Object { $_.Trim() -ne '' }
$rows = @()
for ($i = 1; $i -lt $lines.Count; $i++) {
  $f = $lines[$i] -split ','
  if ($f.Count -ge 7) {
    $rows += [pscustomobject]@{
      time = [double]$f[0]; id = $f[1]; x = [double]$f[5]; y = [double]$f[6]
    }
  }
}

$globalMin = [double]::MaxValue; $minTime = 0; $minPair = ''
foreach ($g in ($rows | Group-Object time)) {
  $pts = $g.Group
  for ($i = 0; $i -lt $pts.Count; $i++) {
    for ($j = $i + 1; $j -lt $pts.Count; $j++) {
      $dx = $pts[$i].x - $pts[$j].x
      $dy = $pts[$i].y - $pts[$j].y
      $d = [math]::Sqrt($dx*$dx + $dy*$dy)
      if ($d -lt $globalMin) {
        $globalMin = $d; $minTime = [double]$g.Name
        $minPair = "$($pts[$i].id) ↔ $($pts[$j].id)"
      }
    }
  }
}
"最小间距: {0:F3} m @ {1} s ({2})" -f $globalMin, $minTime, $minPair
```

输出：

```
最小间距: 118.073 m @ 11.1 s (UAV-4 ↔ UAV-6)
```
